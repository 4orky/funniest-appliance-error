One honest line from a washing machine that has lost a sock and wants answers. The script weighs thirteen hand-drafted appliance error lines on five craft axes and writes the strongest to `/output/entry.txt`:
> ERROR: One sock found. I searched the drum twice. Its partner is
> missing, and I would like to know what you did with it.
## How to run
Run it with `python3 ./main.py` and the winning line prints to stdout.
The pick is deterministic with no network and no randomness, so the output is byte-identical on every run.
